# Architecture Decision Records

Significant architectural decisions are recorded as numbered ADRs.

## Status

- **Accepted** — agreed, implemented, or pending implementation.
- **Proposed** — under discussion.
- **Superseded** — replaced by a later ADR.

## Format

Each ADR uses the lightweight template:

- **Title**: short statement of the decision.
- **Status**: one of the statuses above.
- **Context**: forces and constraints driving the decision.
- **Decision**: the chosen approach.
- **Consequences**: trade-offs, what it makes easier and harder.
